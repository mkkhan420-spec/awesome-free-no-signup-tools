# Contributing

Suggest a tool by opening a pull request that edits README.md only.

Rules:

- The tool's core feature must be free, and it must work with no signup and no login.
- One tool per pull request.
- Add it at the bottom of the most fitting category, in this format: `- [Name](URL) - Short factual description.`
- The description must be one factual sentence, ending in a full stop, with no marketing words.
- If it is your own tool, say so in the pull request description.
